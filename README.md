# 🚀 Enhancing Fraud Detection using Generative AI (CTGAN)

## 📌 Project Overview
This project focuses on improving fraud detection in highly imbalanced datasets using Generative AI.  
A CTGAN (Conditional Tabular GAN) model is used to generate synthetic fraud transactions, which helps balance the dataset and improve machine learning performance.

---

## 🎯 Objective
- Detect fraudulent transactions more effectively  
- Solve class imbalance problem using synthetic data  
- Improve model performance using data augmentation  

---

## 📊 Dataset
- **Credit Card Fraud Detection Dataset (Kaggle)**
- Features:
  - V1–V28 (PCA transformed)
  - Time
  - Amount
  - Class (0 = Normal, 1 = Fraud)

---

## ⚙️ Methodology

### 1. Exploratory Data Analysis (EDA)
- Class distribution analysis  
- Boxplots for outliers  
- Correlation heatmap  
- PCA visualization  

### 2. Generative AI (CTGAN)
- Trained CTGAN on fraud transactions  
- Generated synthetic fraud data  
- Saved synthetic dataset  

### 3. Data Augmentation
- Combined original + synthetic fraud data  
- Balanced dataset for better learning  

### 4. Model Training
- Used Random Forest Classifier  
- Trained on:
  - Original dataset  
  - Augmented dataset  

### 5. Evaluation
- Compared performance before and after augmentation  
- Metrics used:
  - Accuracy  
  - Precision  
  - Recall  
  - F1-score  
- Confusion matrix visualization  

---

## 📈 Results
- Improved fraud detection performance  
- Increased recall for fraud class  
- Reduced false negatives  
- Better model generalization
